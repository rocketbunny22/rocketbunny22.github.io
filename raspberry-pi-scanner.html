Raspberry Pi QR Scanner

Building a small, headless check-in kiosk with Python, a Raspberry Pi, and reliable offline queuing.

By Derek Nolt

A practical check-in tool

This project turns a Raspberry Pi Zero 2 W into a QR badge scanner for the Ohio Furniture Market. A Camera Module 3 Wide reads attendee badges, and a Python application sends the check-in data to an authenticated API. There is no screen or browser interface: LEDs and a buzzer provide feedback at the scanner.

Keeping the camera moving

Reading a badge is only one part of the job. Camera capture, QR decoding, API requests, and hardware feedback run independently so a slow network response or a buzzer pattern does not hold up the next scan. The capture buffer keeps the newest frame instead of building up a backlog of old images.

Planning for an unreliable connection

Valid scans are saved to a local SQLite outbox before submission. If the API is unavailable, the scanner queues them for retry when connectivity returns. Duplicate handling reduces repeated submissions while a badge remains in view. Local capture feedback is separate from API confirmation, so recording a scan does not have to wait for the network.

More than a script

The scanner can run as a systemd service and restart after a crash or reboot. Bringing together camera processing, GPIO feedback, persistence, and service management makes this a useful example of the work I enjoy: connecting software to physical hardware to solve a practical problem.
